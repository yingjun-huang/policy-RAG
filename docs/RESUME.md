# 电商售后政策智能问答系统｜Adaptive & Graph-Enhanced RAG

**技术栈：** Python、FastAPI、LangGraph、DeepSeek、BGE、BM25、Qdrant、NetworkX、SSE

面向电商退换货、运费核算与保修咨询场景，针对政策版本混用、跨条款证据缺失及用户信息不完整等问题，构建支持版本过滤、图证据补全与自适应检索的政策问答系统。

- **知识解析与版本治理**：实现标题感知父子分块、表格按行拆分及版本元数据提取，结合Qdrant元数据过滤支持现行政策检索与历史版本对照；175个标注首问中，检索版本匹配率由无过滤混合检索的 **75.4%提升至99.4%**。
- **混合检索与依赖补全**：结合BM25＋BGE双路召回、RRF融合与Cross-Encoder精排，基于NetworkX条款依赖图补全关联证据；相比BM25，文档级 **P@1由74.3%提升至89.7%**；112个复杂首问中，相比无图混合精排，**Complete@5由90.2%提升至93.8%**。
- **自适应路由与受控补检**：使用LangGraph编排策略路由、证据充分性评审与最多两轮检索，区分用户事实缺口与条款证据缺口，分别执行澄清和补检，并支持无增量早停；132个标注首问的 **策略路由准确率为82.6%**。
- **评测验证与服务交付**：构建覆盖单条款、多条款、版本对照及多轮澄清的自建评测集，共189场景、240轮问答；采用LLM-as-Judge三档评分，Chat接口主裁加权正确率 **86.5%**，Reasoner接口复核加权正确率 **82.5%**、判定一致率 **91.2%**；通过FastAPI＋SSE展示节点进度、最终答案与参考条款。

面试备查：Recall@5为88.86%→97.52%；主裁严格正确率85.42%，Reasoner接口严格正确率78.75%。评分按correct/partial/incorrect分别计1/0.5/0。当前Chat与Reasoner请求均由服务端Flash后端处理，接口检查确认思考模式不同，因此称接口双模式复核，不宣称两个独立模型或人工验证。计算器、选择性核验与CPU运行支持作为实现细节，不宣传未测量的质量或推理收益。
